# Daily Development — 2026-10-04

## Summary

Zum Spielzug kann jetzt ein Szenenbild erzeugt werden: ein LLM schreibt aus den
letzten Zügen einen Bildprompt, Modal rendert ihn (Z-Image Turbo, optional mit
SDXL-Verfeinerung), Postgres speichert das Bild, der Play-Screen zeigt es.
Das Feature ist standardmäßig ausgeschaltet. Es lief nur gegen lokale Fakes,
nicht gegen das echte Modal. Zusätzlich liegt das lokale Backend jetzt auf
Host-Port 8001, weil 8000 vom image-refiner belegt ist. Danach schlug der
Wizard im Docker-Setup mit einem technischen Fehler fehl; das ist behoben.
