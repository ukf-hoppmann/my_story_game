# Catalog: HTTP API layer

The reusable routers, schemas, mappers, authentication, dependencies, and error mapping of the HTTP adapter, in `Backend/src/story_game/api/`; the composition root `app.py` is listed in [catalog-infrastructure.md](./catalog-infrastructure.md).

| Building block | Purpose | Use when | Details |
|---|---|---|---|
| `router` (`Backend/src/story_game/api/routers/__init__.py`) | The aggregate `APIRouter` that includes every router module below. | a new router module must be exposed; include it here. | [http-api.md](./http-api.md) |
| `router` in `runs.py` (`Backend/src/story_game/api/routers/runs.py`) | Health check and the run endpoints: list, load, propose, confirm, start playthrough, update configuration, play turn. | an endpoint concerns runs or turns. | [http-api.md](./http-api.md) |
| `router` in `scene_images.py` (`Backend/src/story_game/api/routers/scene_images.py`) | Scene-image capabilities, listing, creation, and content. | an endpoint concerns scene images. | [http-api.md](./http-api.md) |
| `router` in `prompt_profile.py` (`Backend/src/story_game/api/routers/prompt_profile.py`) | Read-only prompt-profile catalog for the wizard. | the UI needs the selectable style options. | [http-api.md](./http-api.md) |
| `router` in `diagnostics.py` (`Backend/src/story_game/api/routers/diagnostics.py`) | Receives frontend tooling-error reports. | the frontend reports an error to the backend log. | [http-api.md](./http-api.md) |
| `router` in `settings.py` (`Backend/src/story_game/api/routers/settings.py`) | Read access to the world-tracking status for signed-in users. | the UI shows whether world tracking is on. | [http-api.md](./http-api.md) |
| `router` in `admin_prompts.py` (`Backend/src/story_game/api/routers/admin_prompts.py`) | Admin endpoints for prompt text, history, custom options, archive, restore, purge, bulk removal, and reset. | an admin endpoint manages prompts. | [http-api.md](./http-api.md) |
| `router` in `admin_models.py` (`Backend/src/story_game/api/routers/admin_models.py`) | Admin endpoints for per-task model settings, their history, and reset. | an admin endpoint manages model settings. | [http-api.md](./http-api.md) |
| `router` in `admin_settings.py` (`Backend/src/story_game/api/routers/admin_settings.py`) | Admin endpoint to read and change the world-tracking switch. | an admin endpoint manages application settings. | [http-api.md](./http-api.md) |
| `ApiDependencies` (`Backend/src/story_game/api/dependencies.py`) | Frozen bundle of the application operations the routers use; optional capabilities (`scene_images`, `model_settings`, `prompt_management`, `world_tracking`) are `None` when absent. | a router needs an operation; add the operation as a field and wire it in the composition root. | [http-api.md](./http-api.md) |
| `get_api_dependencies` (`Backend/src/story_game/api/dependencies.py`) | FastAPI dependency returning the installed `ApiDependencies`. | a route handler needs operations. | [dependencies.py](../../../Backend/src/story_game/api/dependencies.py) |
| `get_current_initiator` (`Backend/src/story_game/api/dependencies.py`) | FastAPI dependency: the verified Bearer token as a `RunInitiator`; 401 otherwise. | a route acts on behalf of a user; every router uses this for identity (tests override it). | [dependencies.py](../../../Backend/src/story_game/api/dependencies.py) |
| `get_verified_caller` (`Backend/src/story_game/api/dependencies.py`) | FastAPI dependency: the verified `VerifiedCaller` with realm roles; 401 otherwise. | a route needs the roles or the username as well. | [dependencies.py](../../../Backend/src/story_game/api/dependencies.py) |
| `require_admin` (`Backend/src/story_game/api/dependencies.py`) | FastAPI dependency: like `get_verified_caller` but 403 unless the caller holds `ADMIN_ROLE` (`admin`). | a route is admin-only; the backend is the only enforcement point. | [dependencies.py](../../../Backend/src/story_game/api/dependencies.py) |
| `KeycloakTokenVerifier` (`Backend/src/story_game/api/auth/token_verifier.py`) | Verifies signature (JWKS), issuer, expiry, and optional audience; `verify` and `verify_caller`. | a Bearer token must be validated; raises `TokenVerificationError`. | [token_verifier.py](../../../Backend/src/story_game/api/auth/token_verifier.py) |
| `VerifiedCaller` (`Backend/src/story_game/api/auth/token_verifier.py`) | Verified identity: `initiator`, `roles`, optional `username`. | code needs the caller's identity and roles after verification. | [token_verifier.py](../../../Backend/src/story_game/api/auth/token_verifier.py) |
| `unwrap` / `OperationFailed` (`Backend/src/story_game/api/results.py`) | `unwrap(result)` returns the data of a `Success` or raises `OperationFailed` carrying the typed error. | a route calls an operation; always unwrap instead of checking `Failure` in the route. | [results.py](../../../Backend/src/story_game/api/results.py) |
| `register_error_handlers` (`Backend/src/story_game/api/errors.py`) | Installs the handlers for `OperationFailed`, `RevisionConflictError` (409), `DomainError` (422), and `HTTPException`; the body is `{error, detail, ...context}`. Per-family status tables map each error kind to a status and code. | a new application error family must become an HTTP error; extend the tables here, never build error responses in a route. | [http-api.md](./http-api.md) |
| `APIModel` (`Backend/src/story_game/api/schemas/common.py`) | Pydantic base for every HTTP model: forbids extra fields and strips strings. | a new request or response model is added. | [common.py](../../../Backend/src/story_game/api/schemas/common.py) |
| `GameDocument` / `GameStateModel` / `WorldStateModel` / `StoryStateModel` (`Backend/src/story_game/api/schemas/state.py`) | HTTP shapes of a loaded game and its world and story state. | a response or request carries a game state. | [http-api.md](./http-api.md) |
| `WorldEntityModel` and the other domain-shaped models (`Backend/src/story_game/api/schemas/common.py`) | HTTP twins of the domain values: `VisibilityModel`, `ConditionModel`, `ActorProfileModel`, `WorldEntityModel`, `EntityLinkModel`, `FactModel`, `KnowledgeEntryModel`, `WorldRuleModel`, `GoalModel`, `StoryTurnModel`, `StorySummarySegmentModel`, `StoryInitializationModel`, `GameRunModel`, `GameRunMemberModel`. | a model embeds a domain value; reuse these instead of declaring new twins. | [http-api.md](./http-api.md) |
| `GameConfigurationModel` / `PromptProfileModel` / `EditablePromptProfileModel` (`Backend/src/story_game/api/schemas/common.py`) | HTTP shapes of the configuration, the full prompt profile, and the profile subset a client may edit. | a request or response carries a configuration. | [http-api.md](./http-api.md) |
| `ProposeRunRequestModel` / `RunProposalModel` / `ConfirmRunProposalRequestModel` (`Backend/src/story_game/api/schemas/runs.py`) | Wizard shapes: propose a run, the proposal, and the confirmation with `CharacterDecisionModel` and `ItemDecisionModel`. | the propose and confirm endpoints change. | [http-api.md](./http-api.md) |
| `PlayTurnRequestModel` / `TurnResultModel` (`Backend/src/story_game/api/schemas/runs.py`) | Turn input and result: the committed `state`, `continuation`, `proposed_change_count`, and `summary_failed`. | the play-turn endpoint changes. | [http-api.md](./http-api.md) |
| `UpdateConfigurationRequestModel` / `RunSummaryModel` / `RunSummaryListModel` (`Backend/src/story_game/api/schemas/runs.py`) | Configuration update body and the library list shapes. | the configuration or list endpoints change. | [http-api.md](./http-api.md) |
| `PromptPackageCatalogModel` (`Backend/src/story_game/api/schemas/prompt_profile.py`) | The selectable prompt-profile catalog: `PromptCategoryModel` with `PromptOptionModel`. | the catalog endpoint changes. | [http-api.md](./http-api.md) |
| Admin models (`Backend/src/story_game/api/schemas/admin_prompts.py`, `Backend/src/story_game/api/schemas/admin_models.py`) | Prompt admin shapes (`PromptVersionModel`, `PromptListModel`, `UpdatePromptTextRequestModel`, `CreatePromptOptionRequestModel`, `RemovePromptOptionsRequestModel`, `RemovalResultModel`, `ResetPromptsRequestModel`) and model-settings shapes (`ModelSettingModel`, `ModelSettingsOverviewModel`, `UpdateModelSettingRequestModel`, `ResetModelSettingsRequestModel`). | an admin endpoint changes. | [http-api.md](./http-api.md) |
| Scene-image and settings models (`Backend/src/story_game/api/schemas/scene_images.py`, `Backend/src/story_game/api/schemas/settings.py`) | `SceneImageModel`, `SceneImageListModel`, `CreateSceneImageRequestModel`, `SceneImageCapabilitiesModel`, `WorldTrackingModel`, `UpdateWorldTrackingRequestModel`, `WorldTrackingStatusModel`. | the scene-image or world-tracking endpoints change. | [http-api.md](./http-api.md) |
| `FrontendErrorReportModel` (`Backend/src/story_game/api/schemas/diagnostics.py`) | Body of a frontend tooling-error report. | the diagnostics endpoint changes. | [http-api.md](./http-api.md) |
| `game_to_api` / `game_from_api` (`Backend/src/story_game/api/mappers/state.py`) | Translate a `LoadedGame` to a `GameDocument` and back, including world, story, visibility, and configuration. | a route converts a whole game between domain and HTTP. | [state.py](../../../Backend/src/story_game/api/mappers/state.py) |
| `game_state_to_api` (`Backend/src/story_game/api/mappers/state.py`) | Translates a `GameState` to a `GameStateModel`. | a response carries only a state. | [state.py](../../../Backend/src/story_game/api/mappers/state.py) |
| `proposal_to_api` (`Backend/src/story_game/api/mappers/state.py`) | Translates a `GameRunProposal` to a `RunProposalModel`. | a response carries a proposal. | [state.py](../../../Backend/src/story_game/api/mappers/state.py) |
| `prompt_package_to_api` (`Backend/src/story_game/api/mappers/prompt_profile.py`) | Translates a `PromptPackage` to the public `PromptPackageCatalogModel`. | a response exposes the prompt catalog. | [prompt_profile.py](../../../Backend/src/story_game/api/mappers/prompt_profile.py) |
| `DEFAULT_GAME_CONFIGURATION` (`Backend/src/story_game/api/default_configuration.py`) | The fixed server-side `GameConfiguration` (package `story.base` version 1, German); the control mode is overridden per request. | a run is proposed and the base configuration is needed. | [default_configuration.py](../../../Backend/src/story_game/api/default_configuration.py) |
