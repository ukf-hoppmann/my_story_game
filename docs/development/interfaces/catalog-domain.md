# Catalog: Domain layer

The reusable building blocks of the Domain layer, in `Backend/src/story_game/domain/`; every class is a frozen, slotted dataclass or enum, and the package re-exports them from `story_game.domain`.

| Building block | Purpose | Use when | Details |
|---|---|---|---|
| `DomainError` (`Backend/src/story_game/domain/errors.py`) | Base class of every domain rule violation. | a caller must catch any domain rejection (the API maps it to HTTP 422) instead of inventing a new base exception. | [errors.py](../../../Backend/src/story_game/domain/errors.py) |
| `ValidationError` (`Backend/src/story_game/domain/errors.py`) | A value or invariant is invalid. | a new domain value object or aggregate rejects bad input in `__post_init__`. | [errors.py](../../../Backend/src/story_game/domain/errors.py) |
| `InvalidReferenceError` (`Backend/src/story_game/domain/errors.py`) | A reference points at an unknown entity, link, fact, goal, or member. | code resolves a `StableId` against a `WorldState` or `GameState` and the target does not exist. | [errors.py](../../../Backend/src/story_game/domain/errors.py) |
| `RevisionConflictError` (`Backend/src/story_game/domain/errors.py`) | A change was built on a revision that is no longer current. | code compares an expected `StateRevision` with the current one (optimistic concurrency). | [errors.py](../../../Backend/src/story_game/domain/errors.py) |
| `ChangeRejectedError` (`Backend/src/story_game/domain/errors.py`) | The state refuses a change that is not an approved change set or breaks turn consistency. | the domain must reject a structurally wrong change that is neither a bad value nor a stale revision. | [errors.py](../../../Backend/src/story_game/domain/errors.py) |
| `StableId` (`Backend/src/story_game/domain/value_objects.py`) | UUID-backed identifier; `StableId.new()` creates one, `StableId.parse(value)` accepts a `UUID` or string. | any entity, link, fact, goal, run, turn, or proposal needs an identity; never pass raw UUID strings between layers. | [domain-model.md](./domain-model.md) |
| `StateRevision` (`Backend/src/story_game/domain/value_objects.py`) | Positive state revision counter (≥ 1) with `.next()`. | code versions a `GameState` or checks the expected revision of a write. | [domain-model.md](./domain-model.md) |
| `StorySequence` (`Backend/src/story_game/domain/value_objects.py`) | Positive turn sequence number. | code addresses a story turn or the span of a summary segment. | [domain-model.md](./domain-model.md) |
| `EntityKind` (`Backend/src/story_game/domain/value_objects.py`) | Enum: character, location, item, creature, faction. | code classifies a `WorldEntity`. | [domain-model.md](./domain-model.md) |
| `ActorRole` (`Backend/src/story_game/domain/value_objects.py`) | Enum: player, npc, neutral. | code needs the role of an acting entity; extraction creates `neutral` actors and the player role is assigned at proposal confirmation. | [domain-model.md](./domain-model.md) |
| `RelationKind` (`Backend/src/story_game/domain/value_objects.py`) | Enum of link kinds: located_in, possesses, contains, member_of, knows, allied_with, hostile_to, related_to. | code creates or interprets an `EntityLink`. | [domain-model.md](./domain-model.md) |
| `VisibilityScope` (`Backend/src/story_game/domain/value_objects.py`) | Enum: public, player_known, actor_known, director_only. | code reads or maps who may see a fact, link, or rule. | [domain-model.md](./domain-model.md) |
| `Visibility` (`Backend/src/story_game/domain/value_objects.py`) | Scope plus an actor id that is required for `actor_known` and forbidden otherwise; factories `public()`, `player_known()`, `actor_known(id)`, `director_only()`. | code attaches visibility to a `Fact`, `EntityLink`, or `WorldRule`. | [domain-model.md](./domain-model.md) |
| `GameRunStatus` (`Backend/src/story_game/domain/value_objects.py`) | Enum: draft, active, paused, completed. | code checks whether a run is playable (turns need `active`) or is a confirmable draft. | [domain-model.md](./domain-model.md) |
| `GameRole` (`Backend/src/story_game/domain/value_objects.py`) | Enum: owner, player (membership role). | code assigns or checks the role of a `GameRunMember`. | [domain-model.md](./domain-model.md) |
| `GoalKind` (`Backend/src/story_game/domain/value_objects.py`) | Enum: main, side. | code creates or classifies a `Goal`. | [domain-model.md](./domain-model.md) |
| `GoalStatus` (`Backend/src/story_game/domain/value_objects.py`) | Enum of goal states (open, completed, failed). | code updates or filters goals. | [domain-model.md](./domain-model.md) |
| `ActorProfile` (`Backend/src/story_game/domain/world.py`) | Actor marker of an entity; carries the `ActorRole`. | a `WorldEntity` of kind character, creature, or faction acts in the story. | [domain-model.md](./domain-model.md) |
| `Condition` (`Backend/src/story_game/domain/world.py`) | A named state on an entity (name plus description). | an entity carries a temporary state or trait. | [domain-model.md](./domain-model.md) |
| `WorldEntity` (`Backend/src/story_game/domain/world.py`) | A character, location, item, creature, or faction with label, aliases, description, conditions, optional `ActorProfile`. | code represents any thing in the world; `is_actor` tells whether it acts. | [domain-model.md](./domain-model.md) |
| `EntityLink` (`Backend/src/story_game/domain/world.py`) | Directed typed relation between two entities with optional quantity and description. | code records where something is, who owns it, or who relates to whom. | [domain-model.md](./domain-model.md) |
| `Fact` (`Backend/src/story_game/domain/world.py`) | A statement about the world with optional subject and `Visibility`. | code stores a world truth the story established. | [domain-model.md](./domain-model.md) |
| `KnowledgeEntry` (`Backend/src/story_game/domain/world.py`) | Records which actor knows which fact: `learned_at` and optional `forgotten_at` as `StorySequence`. | code grants or reads what an actor knows. | [domain-model.md](./domain-model.md) |
| `WorldRule` (`Backend/src/story_game/domain/world.py`) | A standing rule of the world. | code stores a world rule that applies across turns. | [domain-model.md](./domain-model.md) |
| `Goal` (`Backend/src/story_game/domain/world.py`) | A main or side goal with title, description, status, and related entity ids. | code tracks story objectives. | [domain-model.md](./domain-model.md) |
| `WorldState` (`Backend/src/story_game/domain/world.py`) | The invariant-checked world aggregate: entities, links, facts, knowledge, rules, goals, scene locations. Methods: `entity`, `fact`, `goal`, `add_*`, `update_*`, `remove_link`, `remove_fact`, `set_scene_locations`, `add_knowledge`, `inventory`, `location_of`, `primary_scene_location`. | code reads or rebuilds the world; changes return a new `WorldState`. It enforces one `located_in` per source, one possessor per item, `member_of` towards factions, `knows` between actors, and unique location scenes. | [domain-model.md](./domain-model.md) |
| `CreateEntity` (`Backend/src/story_game/domain/changes.py`) | State operation: add an entity. | an approved change set must introduce a new entity. | [domain-model.md](./domain-model.md) |
| `UpdateEntity` (`Backend/src/story_game/domain/changes.py`) | State operation: replace an existing entity. | an approved change set must modify an entity. | [domain-model.md](./domain-model.md) |
| `AddLink` (`Backend/src/story_game/domain/changes.py`) | State operation: add a link. | an approved change set must relate two entities. | [domain-model.md](./domain-model.md) |
| `RemoveLink` (`Backend/src/story_game/domain/changes.py`) | State operation: remove a link by id. | an approved change set must retract a relation. | [domain-model.md](./domain-model.md) |
| `AddFact` (`Backend/src/story_game/domain/changes.py`) | State operation: add a fact. | an approved change set must record a new truth. | [domain-model.md](./domain-model.md) |
| `RemoveFact` (`Backend/src/story_game/domain/changes.py`) | State operation: retire a fact; matching knowledge entries disappear with it. | the story made an earlier fact untrue. | [domain-model.md](./domain-model.md) |
| `SetSceneLocations` (`Backend/src/story_game/domain/changes.py`) | State operation: set where the narration looks (most relevant first; empty clears). | the scene pointer must move, distinct from a `located_in` link. | [domain-model.md](./domain-model.md) |
| `GrantKnowledge` (`Backend/src/story_game/domain/changes.py`) | State operation: add a `KnowledgeEntry`. | an actor learns a fact. | [domain-model.md](./domain-model.md) |
| `AddGoal` (`Backend/src/story_game/domain/changes.py`) | State operation: add a goal. | a new objective appears. | [domain-model.md](./domain-model.md) |
| `UpdateGoal` (`Backend/src/story_game/domain/changes.py`) | State operation: replace a goal. | an objective changes status or text. | [domain-model.md](./domain-model.md) |
| `StateOperation` (`Backend/src/story_game/domain/changes.py`) | Union type of all ten operations above. | code types a list of world operations. | [domain-model.md](./domain-model.md) |
| `ApprovedChangeSet` (`Backend/src/story_game/domain/changes.py`) | Revision-bound tuple of `StateOperation` with `proposal_id` and `base_revision`; the only input `GameState` accepts for world changes. | the application approved model-proposed changes and hands them to the domain, or commits an empty change set. | [domain-model.md](./domain-model.md) |
| `PromptProfile` (`Backend/src/story_game/domain/configuration.py`) | The explicit prompt selection (genre, optional tone, prose_style, perspective, pacing, control_mode, player_agency, consequence, challenge, content_profile, length); `selections()` returns the categories in prompt-assembly order. | code needs the story style choices of a run or the ordered category/option pairs. | [domain-model.md](./domain-model.md) |
| `GameConfiguration` (`Backend/src/story_game/domain/configuration.py`) | Language, `PromptProfile`, narrative boundaries, prompt package id and version for one revision. | code needs everything required to resume a run unchanged. | [domain-model.md](./domain-model.md) |
| `GameRunMember` (`Backend/src/story_game/domain/game_run.py`) | A member of a run (issuer, subject, role, controlled entity ids); `identity` is the (issuer, subject) pair. | code checks membership or which entities a member controls. | [domain-model.md](./domain-model.md) |
| `GameRun` (`Backend/src/story_game/domain/game_run.py`) | Run metadata: id, name, status, current revision, members, timestamps. | code handles a run apart from its revisioned `GameState`. | [domain-model.md](./domain-model.md) |
| `StoryTurn` (`Backend/src/story_game/domain/story.py`) | One completed turn: id, sequence, player input, narration, based-on and resulting revision, completion time. | code stores or reads finished prose turns. | [domain-model.md](./domain-model.md) |
| `StorySummarySegment` (`Backend/src/story_game/domain/story.py`) | Summary text for a span of turns, with the revision that created it. | code stores or reads rolling summary segments (segments are only appended). | [domain-model.md](./domain-model.md) |
| `StoryInitialization` (`Backend/src/story_game/domain/story.py`) | The opening of a run: initial prompt, opening narration, completion time. | code needs the opening text before any turn exists. | [domain-model.md](./domain-model.md) |
| `StoryState` (`Backend/src/story_game/domain/story.py`) | Initialization, turns, summary segments; `add_turn` appends a turn and optional segment. | code reads the prose history; `current_turn_sequence` is the last turn number. | [domain-model.md](./domain-model.md) |
| `GameState` (`Backend/src/story_game/domain/game_state.py`) | The revisioned canonical state (configuration, world, story). Methods: `validate_members`, `apply(ApprovedChangeSet)`, `reconfigure(configuration, base_revision=...)`, `complete_turn(changes, turn, new_summary_segment)`. | code advances a run; every method returns a new state at the next revision and raises on a stale base revision. | [domain-model.md](./domain-model.md) |
