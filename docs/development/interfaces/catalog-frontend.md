# Catalog: Web frontend

The reusable building blocks of the React frontend in `Frontend-Web/src/` (React, Redux Toolkit with RTK Query, react-router, i18next, keycloak-js); the HTTP shapes they call are described in [http-api.md](./http-api.md).

| Building block | Purpose | Use when | Details |
|---|---|---|---|
| `client` functions (`Frontend-Web/src/api/client.ts`) | One typed function per endpoint (`listRuns`, `loadRun`, `proposeRun`, `confirmRun`, `startPlaythrough`, `updateConfiguration`, `playTurn`, the scene-image, admin prompt, admin model, and world-tracking calls, `reportFrontendError`, `checkHealth`); the base URL is `VITE_API_BASE_URL` (default `http://localhost:8000`). | a screen needs a backend call; add the endpoint function here, never call `fetch` elsewhere. | [http-api.md](./http-api.md) |
| `ApiError` (`Frontend-Web/src/api/client.ts`) | Error thrown for a non-success response with `status`, `body`, and `code`. | code must tell backend error codes apart. | [client.ts](../../../Frontend-Web/src/api/client.ts) |
| `setAuthHeaderProvider` (`Frontend-Web/src/api/client.ts`) | Installs the function that supplies the Bearer header for every request. | the auth module wires itself to the client (done once by `auth.ts`). | [client.ts](../../../Frontend-Web/src/api/client.ts) |
| `ensureAuth` / `checkSession` / `login` / `logout` (`Frontend-Web/src/api/auth.ts`) | Keycloak session handling: `ensureAuth` redirects to login when needed, `checkSession` is a silent check without redirect. | a route needs a signed-in user or the UI needs the session state. | [auth.ts](../../../Frontend-Web/src/api/auth.ts) |
| `currentUsername` / `isAdmin` (`Frontend-Web/src/api/auth.ts`) | The signed-in user's name and whether they hold the admin role. | the UI shows the user or hides admin-only entries (the backend enforces the role). | [auth.ts](../../../Frontend-Web/src/api/auth.ts) |
| `toQueryError` (`Frontend-Web/src/api/queryError.ts`) | Normalizes any thrown value into a `QueryError` with `code`; a 401 becomes `session_expired`, a non-API error becomes `tooling_error` and is reported to the backend. | a query function catches an error; use it so every screen sees the same error shape. | [queryError.ts](../../../Frontend-Web/src/api/queryError.ts) |
| `SESSION_EXPIRED_CODE` / `TOOLING_ERROR_CODE` (`Frontend-Web/src/api/queryError.ts`) | The two frontend-owned error codes. | code branches on those codes. | [queryError.ts](../../../Frontend-Web/src/api/queryError.ts) |
| `apiSlice` (`Frontend-Web/src/api/apiSlice.ts`) | The RTK Query slice wrapping the client functions with cache tags (Run, SceneImage, AdminPrompt, AdminModel, WorldTracking); it exports the hooks below. | a component reads or writes backend data; use or add a hook here instead of calling the client in an effect. | [apiSlice.ts](../../../Frontend-Web/src/api/apiSlice.ts) |
| `useListRunsQuery` / `useLoadRunQuery` / `usePromptProfileCatalogQuery` (`Frontend-Web/src/api/apiSlice.ts`) | Hooks for the library list, one run, and the prompt-profile catalog. | a screen shows runs or the style catalog. | [apiSlice.ts](../../../Frontend-Web/src/api/apiSlice.ts) |
| `useProposeRunMutation` / `useConfirmRunMutation` / `useStartPlaythroughMutation` / `usePlayTurnMutation` (`Frontend-Web/src/api/apiSlice.ts`) | Mutation hooks for the wizard and the play screen. | a screen proposes, confirms, starts, or plays a run. | [apiSlice.ts](../../../Frontend-Web/src/api/apiSlice.ts) |
| `useSceneImageCapabilitiesQuery` / `useListSceneImagesQuery` / `useCreateSceneImageMutation` (`Frontend-Web/src/api/apiSlice.ts`) | Scene-image hooks. | a screen reads or requests scene images (usually through `useSceneImages`). | [apiSlice.ts](../../../Frontend-Web/src/api/apiSlice.ts) |
| Admin hooks (`Frontend-Web/src/api/apiSlice.ts`) | Prompt hooks (`useListAdminPromptsQuery`, `usePromptHistoryQuery`, `useSavePromptTextMutation`, `useResetPromptsMutation`, `useCreatePromptOptionMutation`, `useArchivePromptOptionMutation`, `useRestorePromptOptionMutation`, `usePurgePromptOptionMutation`, `useRemovePromptOptionsMutation`, `useListArchivedPromptOptionsQuery`), model hooks (`useListAdminModelsQuery`, `useModelHistoryQuery`, `useSaveModelSettingMutation`, `useResetModelSettingsMutation`), and world-tracking hooks (`useWorldTrackingQuery`, `useSaveWorldTrackingMutation`, `useWorldTrackingStatusQuery`). | the admin settings screen reads or changes settings. | [apiSlice.ts](../../../Frontend-Web/src/api/apiSlice.ts) |
| Transport types (`Frontend-Web/src/api/types.ts`) | TypeScript twins of the HTTP models (`GameDocument`, `WorldState`, `StoryState`, `RunProposal`, `SceneImage`, `AdminPromptList`, `AdminModelOverview`, `WorldTrackingSetting`, and the string unions for kinds, roles, and statuses). | code types backend data; extend this file when the API changes. | [types.ts](../../../Frontend-Web/src/api/types.ts) |
| `store` / `RootState` / `AppDispatch` (`Frontend-Web/src/app/store.ts`) | The Redux store combining the `app`, `wizard`, and `api` reducers. | a new slice must be registered. | [store.ts](../../../Frontend-Web/src/app/store.ts) |
| `useAppDispatch` / `useAppSelector` (`Frontend-Web/src/app/hooks.ts`) | Typed Redux hooks. | a component uses Redux state; use these instead of the untyped hooks. | [hooks.ts](../../../Frontend-Web/src/app/hooks.ts) |
| `useSession` (`Frontend-Web/src/app/useSession.ts`) | Hook returning `Session` (`checking`, `anonymous`, or `authenticated` with username and admin flag) from a silent session check; never redirects. | the app chrome shows the signed-in state. | [useSession.ts](../../../Frontend-Web/src/app/useSession.ts) |
| `RequireAuth` (`Frontend-Web/src/app/RequireAuth.tsx`) | Layout route that runs `ensureAuth` and renders its children only when signed in. | a route must be reachable only after login. | [RequireAuth.tsx](../../../Frontend-Web/src/app/RequireAuth.tsx) |
| `RequireAdmin` (`Frontend-Web/src/app/RequireAdmin.tsx`) | Layout route that shows a forbidden message unless the user is admin; nest it inside `RequireAuth`. | a route is admin-only. | [RequireAdmin.tsx](../../../Frontend-Web/src/app/RequireAdmin.tsx) |
| `routes` (`Frontend-Web/src/routes/routes.tsx`) | The route table: `/` Landing (public), `/library`, `/new`, `/stories/:runId` behind `RequireAuth`, and `/settings` additionally behind `RequireAdmin`, all inside `AppShell`. | a screen is added; tests build a memory router from the same table. | [routes.tsx](../../../Frontend-Web/src/routes/routes.tsx) |
| `router` (`Frontend-Web/src/routes/router.tsx`) | The browser router created from `routes`. | the app entry mounts the router. | [router.tsx](../../../Frontend-Web/src/routes/router.tsx) |
| `AppShell` (`Frontend-Web/src/routes/AppShell/AppShell.tsx`) | Root layout with the persistent `AppHeader`, sign-in or menu, and sign-out. | a page needs the common frame. | [AppShell.tsx](../../../Frontend-Web/src/routes/AppShell/AppShell.tsx) |
| `AppHeader` / `HeaderMenu` (`Frontend-Web/src/components/AppHeader/AppHeader.tsx`, `Frontend-Web/src/components/AppHeader/HeaderMenu.tsx`) | The top bar with the brand link and a right-side slot, and the hamburger menu with the admin entries. | the header content changes. | [AppHeader.tsx](../../../Frontend-Web/src/components/AppHeader/AppHeader.tsx) |
| `Button` (`Frontend-Web/src/components/Button/Button.tsx`) | Button primitive with `variant` primary or ghost and an optional icon. | any button; do not style raw `<button>` elements. | [Button.tsx](../../../Frontend-Web/src/components/Button/Button.tsx) |
| `Chip` (`Frontend-Web/src/components/Chip/Chip.tsx`) | Pill control; `selected` makes it a toggle option, omitting it makes it a plain action. | an option picker or quick action. | [Chip.tsx](../../../Frontend-Web/src/components/Chip/Chip.tsx) |
| `Panel` (`Frontend-Web/src/components/Panel/Panel.tsx`) | Bordered card with a title and icon. | a titled sidebar section. | [Panel.tsx](../../../Frontend-Web/src/components/Panel/Panel.tsx) |
| `Accordion` (`Frontend-Web/src/components/Accordion/Accordion.tsx`) | Collapsible item with title, summary, badges, actions; the body renders only while open. | a list of expandable entries, as in settings. | [Accordion.tsx](../../../Frontend-Web/src/components/Accordion/Accordion.tsx) |
| `Tabs` / `TabItem` (`Frontend-Web/src/components/Tabs/Tabs.tsx`) | Accessible tab bar with arrow-key navigation and the active tab's content. | a view switches between sections. | [Tabs.tsx](../../../Frontend-Web/src/components/Tabs/Tabs.tsx) |
| `ErrorBanner` (`Frontend-Web/src/components/ErrorBanner/ErrorBanner.tsx`) | The single error display: `session_expired` offers a re-login, `tooling_error` shows generic text, other errors show the backend message; `knownCodes` overrides per screen, `fallbackKey` when no message exists. | a screen shows an error from a query or mutation; never render raw error text. | [ErrorBanner.tsx](../../../Frontend-Web/src/components/ErrorBanner/ErrorBanner.tsx) |
| `ImageSlot` (`Frontend-Web/src/components/ImageSlot/ImageSlot.tsx`) | Image or placeholder with the same footprint; `shape` rect or circle. | an illustration or portrait may not exist yet. | [ImageSlot.tsx](../../../Frontend-Web/src/components/ImageSlot/ImageSlot.tsx) |

| Icons (`Frontend-Web/src/icons/index.tsx`) | The shared SVG icon components (for example `PlusIcon`, `ChevronDownIcon`, `PersonIcon`, `ImagePlaceholderIcon`). | an icon is needed; add new ones here. | [index.tsx](../../../Frontend-Web/src/icons/index.tsx) |
| `i18n` (`Frontend-Web/src/i18n/index.ts`) | Initializes i18next with the bundled German translations from `Frontend-Web/src/i18n/de/translation.json`. | any user-visible text; use `useTranslation` keys instead of literals. | [index.ts](../../../Frontend-Web/src/i18n/index.ts) |
