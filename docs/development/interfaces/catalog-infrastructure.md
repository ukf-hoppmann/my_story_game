# Catalog: Infrastructure layer

The reusable adapters, configuration loaders, and the composition root, in `Backend/src/story_game/infrastructure/` plus `Backend/src/story_game/api/app.py` (the composition root lives in the API package, not in infrastructure).

| Building block | Purpose | Use when | Details |
|---|---|---|---|
| `create_app` (`Backend/src/story_game/api/app.py`) | The composition root: builds the FastAPI app and, in its lifespan, wires stores, adapters, operations, and policies into `ApiDependencies`; the module-level `app` is `create_app()`. Private helpers `_compose_*` wire one use case each. | a new operation, port implementation, or policy must be wired; add the wiring here and keep workflow decisions in the application layer. | [application-composition.md](./application-composition.md) |
| `ApiSettings` (`Backend/src/story_game/api/config.py`) | Environment-backed settings: `from_environment` reads `STORY_GAME_POSTGRES_DSN`, `STORY_GAME_PROMPT_ROOT`, `STORY_GAME_AUTO_MIGRATE`, `STORY_GAME_CONFIG_PATH`, `STORY_GAME_LLM_CONFIG_PATH`, `STORY_GAME_CORS_ALLOWED_ORIGINS`, the `STORY_GAME_KEYCLOAK_*` and `STORY_GAME_DEV_*` values, and the API title and version. | the composition root or a test needs a deployment setting; add new environment keys here. | [config.py](../../../Backend/src/story_game/api/config.py) |
| `PostgresConnectionFactory` (`Backend/src/story_game/infrastructure/persistence/postgres/connection.py`) | Opens independent psycopg connections from a DSN (rows addressable by column name); rejects an empty DSN. | a Postgres adapter needs a connection. | [persistence.md](./persistence.md) |
| `PostgresSchemaMigrator` (`Backend/src/story_game/infrastructure/persistence/postgres/migrations.py`) | Applies the bundled SQL files of `Backend/src/story_game/infrastructure/persistence/postgres/migrations` in order, once each, recorded in `schema_migrations`. | the schema must be created or upgraded; add a new numbered SQL file instead of editing an old one. | [persistence.md](./persistence.md) |
| `main` (`Backend/src/story_game/infrastructure/persistence/postgres/migrate.py`) | Command-line entry that runs the migrator; requires `STORY_GAME_POSTGRES_DSN`. | the schema must be migrated outside the app start. | [migrate.py](../../../Backend/src/story_game/infrastructure/persistence/postgres/migrate.py) |
| `PostgresGameStore` (`Backend/src/story_game/infrastructure/persistence/postgres/store.py`) | Implements the narrow game-state ports (`create`, `load_run`, `load_state`, `update_configuration`, `commit_turn`, `list_for_member`); one atomic transaction per write, revision-checked. | runs, states, or turns are read or written; never write game tables from another adapter. | [persistence.md](./persistence.md) |
| `PostgresSnapshotReader` / `PostgresSnapshotWriter` (`Backend/src/story_game/infrastructure/persistence/postgres/snapshot_reader.py`, `Backend/src/story_game/infrastructure/persistence/postgres/snapshot_writer.py`) | Read and write one full revisioned snapshot; delegate to `WorldSnapshotReader`, `WorldSnapshotWriter`, `StorySnapshotReader`, `StorySnapshotWriter`. | `PostgresGameStore` internals change how a revision is stored. | [persistence.md](./persistence.md) |
| `row_mapping` helpers (`Backend/src/story_game/infrastructure/persistence/postgres/row_mapping.py`) | Pairs `*_values` and `*_from_row` for configuration, visibility, entity, link, fact, knowledge, rule, and goal, plus `jsonb` and `stable_id_from_row`. | a domain value is stored in or restored from a row; reuse these mappings. | [row_mapping.py](../../../Backend/src/story_game/infrastructure/persistence/postgres/row_mapping.py) |
| `PostgresPromptStore` (`Backend/src/story_game/infrastructure/persistence/postgres/prompt_store.py`) | Versioned prompt storage in `system_prompts`: `list_active`, `list_archived`, `list_history`, `append_versions`, `deactivate_entry`, `restore_entry`, `purge_entry`. | prompt versions are stored or read (implements `PromptVersionReader`, `PromptVersionWriter`). | [persistence.md](./persistence.md) |
| `PostgresPromptOptionUsage` (`Backend/src/story_game/infrastructure/persistence/postgres/prompt_store.py`) | Tells whether any stored game revision still selects a genre, tone, or prose-style option (`is_option_used`). | an archive or purge must be blocked for options in use. | [persistence.md](./persistence.md) |
| `DbPromptPackageCatalog` (`Backend/src/story_game/infrastructure/persistence/postgres/prompt_store.py`) | The runtime `PromptPackageCatalog`: assembles the active stored versions into a `PromptPackage`; no active versions raises `PromptPackageNotFoundError`, a store error `InvalidPromptPackageError`. | an operation loads prompt text at run time; use this instead of reading prompt files. | [llm-integration.md](./llm-integration.md) |
| `PostgresModelSettingsStore` (`Backend/src/story_game/infrastructure/persistence/postgres/model_settings_store.py`) | Versioned per-task model settings in `llm_task_settings`: `list_active`, `list_history`, `append_versions`. | model settings are stored or read. | [persistence.md](./persistence.md) |
| `PostgresSceneImageStore` (`Backend/src/story_game/infrastructure/persistence/postgres/scene_image_store.py`) | Stores scene images: `create_pending`, `find_active`, `save_prompts`, `complete`, `fail`, `get`, `list_for_run`, `load_content`. | scene image records or bytes are stored or read. | [persistence.md](./persistence.md) |
| `PostgresWorldTrackingStore` (`Backend/src/story_game/infrastructure/persistence/postgres/world_tracking_store.py`) | Stores the single world-tracking setting: `load`, `save`. | the world-tracking setting is stored or read. | [persistence.md](./persistence.md) |
| `InMemoryProposalStore` (`Backend/src/story_game/infrastructure/persistence/in_memory_proposal_store.py`) | Thread-safe `InitialProposalStore` with a time-to-live (default 30 minutes); single instance only. | proposals must survive between propose and confirm without a database. | [persistence.md](./persistence.md) |
| `PersistenceError` (`Backend/src/story_game/infrastructure/persistence/errors.py`) | Compatibility aliases of the application store errors: `PersistenceError`, `PersistenceNotFoundError`, `PersistenceConflictError`, `PersistenceConsistencyError`. | an adapter raises a store failure; prefer the `GameStateStoreError` family from the application. | [errors.py](../../../Backend/src/story_game/infrastructure/persistence/errors.py) |
| `OpenAiCompatibleClient` (`Backend/src/story_game/infrastructure/llm/openai_compatible/client.py`) | HTTP client for OpenAI-compatible `chat/completions` with JSON-schema output: `complete(ChatRequest)` and `close()`; settings are re-resolved on every call; maps HTTP and network failures to `TransportError`. | a provider adapter calls a chat endpoint; reuse it instead of writing HTTP code. | [llm-integration.md](./llm-integration.md) |
| `OpenAiCompatibleSettings` (`Backend/src/story_game/infrastructure/llm/openai_compatible/client.py`) | Base URL, optional API token (hidden from `repr`), timeout. | a provider needs connection settings. | [client.py](../../../Backend/src/story_game/infrastructure/llm/openai_compatible/client.py) |
| `ChatRequest` / `ChatResponse` / `ChatMessage` / `JsonSchema` (`Backend/src/story_game/infrastructure/llm/openai_compatible/models.py`) | Transport values of one chat completion. | a wire module builds a request or reads a response. | [models.py](../../../Backend/src/story_game/infrastructure/llm/openai_compatible/models.py) |
| `TransportError` / `TransportErrorKind` (`Backend/src/story_game/infrastructure/llm/openai_compatible/errors.py`) | Internal transport failure with `kind`, `message`, `retryable` (set for timeouts, network failures, 5xx, and 429). | transport code reports a failure before it is translated to the application. | [llm-integration.md](./llm-integration.md) |
| `to_llm_error` (`Backend/src/story_game/infrastructure/llm/openai_compatible/error_mapping.py`) | Maps a `TransportError` one-to-one to an `LLMError`, keeping `retryable`. | an adapter catches a `TransportError`. | [llm-integration.md](./llm-integration.md) |
| `strict_json_schema` (`Backend/src/story_game/infrastructure/llm/json_schema.py`) | Builds a strict JSON schema from a Pydantic model with every property required. | a new wire model needs a structured-output schema. | [json_schema.py](../../../Backend/src/story_game/infrastructure/llm/json_schema.py) |
| `WireNarrationWithOptions` (`Backend/src/story_game/infrastructure/llm/openai_compatible/narration_wire.py`) | Wire model for prose plus continuation options. | a wire needs narration with next-action choices. | [narration_wire.py](../../../Backend/src/story_game/infrastructure/llm/openai_compatible/narration_wire.py) |
| `story_generation_wire` (`Backend/src/story_game/infrastructure/llm/openai_compatible/story_generation_wire.py`) | Request building and response parsing for story generation (schema `story_generation`). | an adapter builds or parses a story-generation call. | [llm-integration.md](./llm-integration.md) |
| `story_initialization_wire` (`Backend/src/story_game/infrastructure/llm/openai_compatible/story_initialization_wire.py`) | Request building and response parsing for the opening prose. | an adapter builds or parses an initialization call. | [llm-integration.md](./llm-integration.md) |
| `initial_extraction_wire` (`Backend/src/story_game/infrastructure/llm/openai_compatible/initial_extraction_wire.py`) | Wire schema `world_initialization` and its mapping to `WorldInitializationCandidate`. | an adapter builds or parses the initial world extraction. | [llm-integration.md](./llm-integration.md) |
| `turn_extraction_wire` (`Backend/src/story_game/infrastructure/llm/openai_compatible/turn_extraction_wire.py`) | Wire schema `turn_changes` in two variants (with and without evidence, selected by `with_evidence`) and its mapping to `TurnChangeCandidate`. | an adapter builds or parses the per-turn extraction. | [llm-integration.md](./llm-integration.md) |
| `summary_wire` (`Backend/src/story_game/infrastructure/llm/openai_compatible/summary_wire.py`) | Request building and response parsing for summaries. | an adapter builds or parses a summary call. | [llm-integration.md](./llm-integration.md) |
| `scene_image_wire` (`Backend/src/story_game/infrastructure/llm/openai_compatible/scene_image_wire.py`) | `build_prompt_request`, `build_compact_request`, and `parse_response` for image prompts. | an adapter builds or parses an image-prompt call. | [llm-integration.md](./llm-integration.md) |
| `normalize_link_quantity` (`Backend/src/story_game/infrastructure/llm/openai_compatible/wire_link.py`) | Drops a link quantity for kinds other than possesses and contains and logs a warning. | a wire maps a model link to a domain candidate. | [wire_link.py](../../../Backend/src/story_game/infrastructure/llm/openai_compatible/wire_link.py) |
| `OpenAiCompatibleSceneImagePromptAdapter` / `OpenAiCompatibleCompactImagePromptAdapter` (`Backend/src/story_game/infrastructure/llm/openai_compatible/scene_image_adapters.py`) | One pair of adapters for all providers, parameterised by provider id and label; implement `SceneImagePromptPort` and `CompactImagePromptPort`. | image prompts are generated; register the pair per provider instead of writing new adapters. | [llm-integration.md](./llm-integration.md) |
| `LmStudioStoryGenerationAdapter` (`Backend/src/story_game/infrastructure/llm/lmstudio/adapter.py`) | `StoryGenerationPort` for LM Studio; the other four LM Studio adapters are `LmStudioStoryInitializationAdapter` (`initialization_adapter.py`), `LmStudioInitialWorldExtractionAdapter` (`initial_extraction_adapter.py`), `LmStudioTurnExtractionAdapter` (`turn_extraction_adapter.py`), `LmStudioStorySummaryAdapter` (`summary_adapter.py`). | the provider `lmstudio` serves a task; each adapter rejects a call for another provider id with `LLMError(CONFIGURATION)`. | [llm-integration.md](./llm-integration.md) |
