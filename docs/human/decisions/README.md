# Entscheidungen

Hier liegen verständliche Entscheidungsdokumente. Sie halten fest, was
entschieden wurde, warum die Entscheidung getroffen wurde, welche Alternativen
betrachtet wurden und welche Folgen daraus entstehen.

Ein Entscheidungsdokument ist kein unverarbeiteter Gesprächsmitschnitt. Ein
relevanter Diskussionsverlauf kann als Kontext enthalten sein, aber die
Entscheidung und ihr Status müssen klar erkennbar bleiben.

Normative Regeln werden nicht hier dupliziert. Wenn eine Entscheidung durch
den Harness oder den Agenten verbindlich erzwungen werden muss, bleibt die
Regelquelle in `.harness/`; dieses Dokument erklärt dann ihren fachlichen
Hintergrund.
