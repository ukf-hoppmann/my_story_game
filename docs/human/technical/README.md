# Technische Dokumentation

Dieser Bereich beschreibt die technische Architektur, das Domainmodell, die
API und die Persistenz so, dass sie auch für Menschen außerhalb des konkreten
Codes nachvollziehbar bleiben.

Die Dokumente beschreiben entweder den aktuellen Stand oder ein ausdrücklich
gekennzeichnetes technisches Zielbild. Geplante technische Umsetzungen, die
noch nicht den aktuellen Stand beschreiben, gehören nach
[`planned/`](planned/).
